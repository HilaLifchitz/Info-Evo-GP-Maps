# Polygenic efficiency (web)

Standalone React copy of the Cursor canvas, for GitHub Pages.

**[Explore the interactive visualization](https://hilalifchitz.github.io/Info-Evo-GP-Maps/index.html)**

```bash
cd web
npm install
npm run dev
```

Build uses `VITE_BASE=/<repo-name>/` in CI so assets work on project Pages.

Python results should land in `public/data/` as JSON; the sliders and lattice already run entirely in the browser.

# Regulatory networks (notes and figures)

Reference material on **genotype–phenotype maps** and information in gene regulation. There is **no simulation code** in this folder.

| File | What it is |
|------|------------|
| `GPmaps_1.pdf`, `GPmaps_2.pdf` | Genotype–phenotype map notes / figures |
| `Information_and_regulation.pdf` | Information-theoretic view of regulation (also copied under [`../docs/`](../docs/)) |
| `Untitled-1.nb` | Mathematica notebook (equilibria / maps) |
| `equilibria.png` | Snapshot figure from that notebook |

Related papers live in [`../docs/`](../docs/). The active simulators are [`../2loci/`](../2loci/) and [`../epistasis_equilibria/`](../epistasis_equilibria/).
